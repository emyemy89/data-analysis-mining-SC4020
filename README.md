# Link Analysis Algorithms: PageRank and HITS

## Overview
This project explores and compares the **PageRank** and **HITS** algorithms for link analysis across multiple datasets.  
The implementation, experiments, and detailed analysis are documented in the accompanying report.

## Project Structure

root/
├── report/ # Contains the final report and contribution breakdown files
├── src/ # Source code implementing PageRank and HITS
└── datasets/ # Datasets used for experiments (Facebook, Wikipedia, Epinions)
